# PGvZNewPlantMod 安装与分发

发布包与 PGvZOnlineMod / PvZWSTools_Inner / 植物娘AI对话 使用同一套约定：
**zip 内不套 `mods/`，根层就是 DLL + 同名文件夹 + 使用说明，直接解压进游戏的 `mods`。**

```text
PGvZNewPlantMod.dll
PGvZNewPlantMod/
├─ PGvZPlantKit.dll
├─ plant_packs.json
├─ plant_packs.template.json
├─ plants/
│  ├─ PGvZNewPlantMod.*.dll   9 个 C# 插件
│  └─ ExamplePlant*.py
└─ assets/
使用说明.txt
update.md                     ← 仅正式包
```

不需要改 APK，也不需要 root。九种植物的卡图、弹体图和 Spine 都在各自插件 DLL 内，
Windows 和 Android 使用同一套文件，不再需要 `spanim` 目录。

## Windows

1. 完全关闭游戏。
2. 把压缩包里的**所有内容**解压到：

   ```text
   %AppData%\ZBC\PlantGirlsVsZombies\mods
   ```

   解压后应直接看到：

   ```text
   ...\mods\PGvZNewPlantMod.dll
   ...\mods\PGvZNewPlantMod\
   ```

3. 重新启动游戏。

不要解压成 `...\mods\PGvZNewPlantMod-1.0.0\mods\...` 或 `...\mods\mods\...`。

## Android

适用包名：`net.pvz.pgvz.zbcteam`。

1. 完全关闭游戏。
2. 把压缩包里的**所有内容**解压到：

   ```text
   /storage/emulated/0/Android/data/net.pvz.pgvz.zbcteam/files/mods
   ```

   解压后应直接看到：

   ```text
   .../files/mods/PGvZNewPlantMod.dll
   .../files/mods/PGvZNewPlantMod/
   ```

3. 重新启动游戏。

Android 11 及以上可能限制文件管理器直接访问 `Android/data`，可以使用系统文件选择器、
USB/MTP 或支持该目录的文件管理器复制。不要解压到 APK 内部，也不需要重新打包 APK。

## 版本说明

- Windows 目标：PGvZ 1.3.2。
- 本机 Android APK：PGvZ 1.3.1，包名 `net.pvz.pgvz.zbcteam`。
- 路径、内嵌 Spine 和 mod 目录已经按两个平台共用设计；当前 C# DLL 仍是用 PC 1.3.2 程序集
  编译的。Android 1.3.1 的实机兼容性需要在 Android 设备上复核；如果游戏程序集接口差异
  导致加载失败，需要按 Android 1.3.1 重新编译对应版本。

## 日志

- Windows：`%AppData%\ZBC\PlantGirlsVsZombies\mods\PGvZNewPlantMod\plant_kit.log`
- Android：`Android/data/net.pvz.pgvz.zbcteam/files/mods/PGvZNewPlantMod/plant_kit.log`

启动日志会打印 `runtime: Windows/Android, Lawn <版本>`，便于确认平台和游戏版本。
