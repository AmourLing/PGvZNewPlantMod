# 已废弃的工程

这里放着停止收录的植物工程：最早移植的九株（超级机枪射手、伏僵塔黄、电鳗香蕉、
桑葚爆破手、球果训练家、牛蒡击球手、瓷砖萝卜、黄金蓓蕾、守卫菇（含隐藏的小守卫菇）），
以及后来加进来的巧克力大炮。

- 宿主只扫 `..\Plants\*\*.csproj` 与 `..\Plants\*in\...\*.dll`（一层），
  放在本目录下的工程既不会被编译，也不会被部署或打包脚本收走。
- 工程本身保留，`Directory.Build.props` 仍能从上级正常解析；要恢复某一株，
  把它的目录移回 `src\Plants\` 并重新加入 `PGvZNewPlantMod.slnx` 即可。
- 定义上的废弃标记是 `CustomPlantDef.Deprecated`（图鉴显示【已废弃】），
  与"是否编译"是两件事。
- 含这些植物的旧存档仍能读取：读档遇到已删除的模组条目会回退成占位并写一条
  `save references a removed custom entry` 日志，不会把存档打成 `.crash`。
